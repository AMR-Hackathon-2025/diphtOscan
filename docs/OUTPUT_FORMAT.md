# diphtOscan Output Format

This document describes the output files generated by diphtOscan and explains the annotation symbols used in results.

## Output Formats

diphtOscan supports multiple output formats, controlled by the `--format` option:

| Format | Option | Files Generated |
|--------|--------|-----------------|
| TSV (default) | `--format tsv` | `{outdir}.txt` |
| JSON | `--format json` | `{outdir}.json` |
| HTML | `--format html` | `{outdir}.html` |
| All | `--format all` | `{outdir}.txt`, `{outdir}.json`, and `{outdir}.html` |

---

## Output Files

When running diphtOscan, the following files are generated in the output directory:

### Main Results Table: `{outdir}.txt`

A tab-separated file containing all analysis results with one row per input assembly.

**Columns include:**
- `species`: Identified species name
- `species_match`: Match strength ("strong", "weak", or empty)
- `ST`: MLST sequence type (e.g., "ST1", "ST1-2LV", or "NA")
- MLST loci columns: `atpA`, `dnaE`, `dnaK`, `fusA`, `leuA`, `odhA`, `rpoB`
- `tox_allele`: Detected tox allele number
- AMR/virulence gene family columns (when `-res_vir` is enabled)
- Integron columns: `CALIN`, `complete`, `In0` (when `-integron` is enabled)
- `GENOMIC_CONTEXT`: Co-located resistance genes

#### Biovar Marker Columns

The following columns indicate biovar-associated genes:
- `spuA`: Spermidine/putrescine utilization gene (associated with biovar gravis)
- `narG`, `narH`, `narI`, `narJ`, `narK`: Nitrate reductase gene cluster (associated with biovar mitis when absent)

Biovar determination is based on the combination of these markers:
- **gravis**: spuA positive, nitrate reductase positive
- **mitis**: spuA negative, nitrate reductase negative
- **belfanti**: Typically spuA negative, nitrate reductase positive

#### Extended Genotyping Columns (`-plus` flag)

When using the `-plus`/`--extend_genotyping` flag, additional virulence gene columns are included:

| Category | Columns |
|----------|---------|
| Pili | SpaA-type, SpaD-type, SpaH-type pili gene clusters |
| Iron Uptake | Siderophore biosynthesis and iron acquisition genes |
| Adhesins | Additional adhesin genes |
| Other Virulence | Stress response and other virulence-associated genes |

These columns follow the same annotation symbols as standard AMR/virulence columns.

### Per-Strain Files

For each input assembly (when `-res_vir` is enabled):

| File | Description |
|------|-------------|
| `{strain}.prot.fa` | Extracted protein sequences for detected genes |
| `{strain}.blast.out` | Raw AMRFinderPlus tabular output |

### iTOL Visualization Files

Template files for Interactive Tree of Life visualization:
- `spuA.txt`: spuA gene presence/absence
- `narG.txt`: narG gene presence/absence
- `TOXIN.txt`: Toxin gene status
- `{AMR_FAMILY}.txt`: Resistance family annotations

### Genomic Context File

`distance_context.txt`: Records distances between adjacent resistance genes on the same contig.

## JSON Output Format

When using `--format json` or `--format both`, diphtOscan generates a structured JSON file with the following schema:

### JSON Structure

```json
{
  "version": "1.8.0",
  "date": "2025-01-26T10:30:00.123456",
  "samples": {
    "sample_name": {
      "species": "C. diphtheriae",
      "species_match": "strong",
      "ST": "ST8",
      "atpA": "1",
      "dnaE": "1",
      "dnaK": "1",
      "fusA": "1",
      "leuA": "1",
      "odhA": "1",
      "rpoB": "1",
      "tox_allele": "1",
      "qc_total_length": "2456789",
      "qc_num_contigs": "45",
      "qc_n50": "123456",
      "qc_gc_percent": "53.4",
      "AMINOGLYCOSIDE": "-",
      "MACROLIDE": "ermX*-5.0%",
      "GENOMIC_CONTEXT": "ermX || tetA;tetR"
    }
  },
  "summary": {
    "total_samples": 10,
    "species_counts": {
      "C. diphtheriae": 7,
      "C. ulcerans": 2,
      "unknown": 1
    },
    "tox_positive": 5,
    "tox_negative": 5
  }
}
```

### JSON Fields

| Field | Type | Description |
|-------|------|-------------|
| `version` | string | diphtOscan version used for analysis |
| `date` | string | ISO 8601 timestamp of analysis |
| `samples` | object | Dictionary of sample results, keyed by sample name |
| `summary` | object | Aggregate statistics across all samples |

### Sample Object Fields

Each sample in the `samples` dictionary contains:

- **Species identification**: `species`, `species_match`
- **MLST results**: `ST`, `atpA`, `dnaE`, `dnaK`, `fusA`, `leuA`, `odhA`, `rpoB`
- **Tox detection**: `tox_allele`
- **QC metrics** (unless `--no-qc`): `qc_total_length`, `qc_num_contigs`, `qc_n50`, `qc_l50`, `qc_largest_contig`, `qc_gc_percent`, `qc_n_percent`
- **AMR/virulence** (when `-res_vir`): Family columns like `AMINOGLYCOSIDE`, `MACROLIDE`, etc.
- **Genomic context**: `GENOMIC_CONTEXT`

### Summary Object Fields

| Field | Type | Description |
|-------|------|-------------|
| `total_samples` | integer | Number of samples analyzed |
| `species_counts` | object | Count of samples per species |
| `tox_positive` | integer | Samples with tox gene detected |
| `tox_negative` | integer | Samples without tox gene |

## HTML Report Format

When using `--format html` or `--format all`, diphtOscan generates a self-contained interactive HTML report.

### HTML Report Features

The HTML report provides an interactive view of your analysis results:

#### Summary Section
- **Total Samples Card**: Shows the count of samples analyzed
- **Species Distribution Card**: Lists species counts with a visual distribution chart
- **Tox Gene Status Card**: Shows tox positive/negative counts and percentage
- **Biovar Distribution Card**: Lists biovar counts (when applicable)
- **AMR Prevalence Card**: Shows resistance gene family prevalences
- **Assembly Quality Card**: Displays average genome length and contig count

#### Results Table
- **Searchable**: Filter samples by typing in the search box
- **Sortable**: Click any column header to sort ascending/descending
- **Color-coded cells**:
  - Species names are color-coded by species
  - Tox-positive samples highlighted in red
  - AMR genes present shown with red background
  - AMR genes absent shown with green background

### Self-Contained Design

The HTML report is fully self-contained with no external dependencies:
- All CSS styles embedded in `<style>` tags
- All JavaScript embedded in `<script>` tags
- Can be opened in any modern web browser
- Can be shared as a single file
- Works offline without internet connection

## Annotation Symbols

### Gene Detection Annotations

These symbols are appended to gene names in the results:

| Symbol | Meaning | Description |
|--------|---------|-------------|
| (none) | Exact match | Perfect match to reference allele (ALLELEX/EXACTX) |
| `*` | BLAST match | Sequence found by BLAST with minor differences |
| `!` | Point mutation | Gene contains a known resistance-conferring point mutation |
| `?` | Partial match | Incomplete gene sequence, not at contig boundary |
| `#` | Internal stop | Gene contains a premature stop codon |
| `_end_of_contig` | Truncation | Gene is truncated at a contig boundary |

### Coverage Percentage

For partial matches, the missing coverage percentage is appended:

```
ermX?-15.2%    # ermX gene with 15.2% missing coverage
pbp2m*-8.0%    # pbp2m gene found by BLAST, 8.0% missing
```

### MLST Annotations

| Annotation | Meaning |
|------------|---------|
| `ST123` | Exact match to sequence type 123 |
| `ST123-1LV` | 1-locus variant of ST123 (1 allele differs) |
| `ST123-2LV` | 2-locus variant of ST123 |
| `0` | No ST could be assigned |
| `NA` | MLST not applicable (not in CdSC) |

**Allele-level annotations:**
| Symbol | Meaning |
|--------|---------|
| `5` | Exact match to allele 5 |
| `5*` | Imprecise match to allele 5 |
| `-` | Allele not detected |

### Tox Gene Annotations

| Annotation | Meaning |
|------------|---------|
| `tox_1` | Exact match to tox allele 1 |
| `tox-NTTB` | Non-Toxigenic Tox-Bearing strain |
| `-` | No tox gene detected |

**NTTB Prediction Rules:**
A strain is classified as NTTB when:
1. The tox gene is detected
2. Coverage is less than 100%
3. The gene is NOT truncated at a contig boundary

## Species Match Strength

The `species_match` column indicates confidence in species identification:

| Value | Mash Distance | Interpretation |
|-------|---------------|----------------|
| `strong` | <= 0.05 | High confidence species match |
| `weak` | <= 0.10 | Low confidence, possible species match |
| (empty) | > 0.10 | Unknown species |

---

## Genomic Context Format

The `GENOMIC_CONTEXT` column shows resistance genes grouped by their genomic location:

```
geneA;geneB;geneC || geneD || geneE;geneF
```

- Genes separated by `;` are co-located (within 8000 bp)
- Genes separated by `||` are on different contigs or distant locations

---

## AMRFinderPlus Method Codes

Internal method codes from AMRFinderPlus (reflected in annotations):

| Code | diphtOscan Symbol | Description |
|------|-------------------|-------------|
| `ALLELEX` | (none) | Exact allele match |
| `EXACTX` | (none) | Exact nucleotide match |
| `POINTX` | `!` | Point mutation detected |
| `BLASTX` | `*` | BLAST alignment match |
| `PARTIALX` | `?` | Partial gene match |
| `PARTIAL_CONTIG_ENDX` | `_end_of_contig` | Truncation at contig boundary |
| `INTERNAL_STOP` | `#` | Contains internal stop codon |

## Example Output

```tsv
strain      species           species_match  ST      atpA  dnaE  dnaK  fusA  leuA  odhA  rpoB  tox_allele  AMINOGLYCOSIDE  MACROLIDE
sample1     C. diphtheriae    strong         ST8     1     1     1     1     1     1     1     1           -               ermX*-5.0%
sample2     C. ulcerans       strong         ST1-1LV 1     1     2*    1     1     1     1     -           aph(3')-Ia      -
sample3     unknown                          NA      -     -     -     -     -     -     -     -           -               -
```

---

## Notes on Interpretation

1. **Missing data (`-`)**: Indicates the feature was not detected, not necessarily absent
2. **Multiple genes**: When multiple genes of the same family are found, they are semicolon-separated: `ermX;ermC`
3. **Coverage thresholds**: Default minimum coverage is 50%, minimum identity is 80%
4. **MLST requirements**: ST calling requires at least half of the 7 loci to have exact matches
